# Intelligent Academic Performance Tracker & Visualizer

## Project Description

The Intelligent Academic Performance Tracker & Visualizer is a Python-based application designed to help students track and understand their academic performance.

The application accepts student details, subject-wise marks and attendance and generates a basic academic performance report.

## Objectives

- Track student academic information.
- Calculate subject-wise performance.
- Assign grades automatically.
- Check attendance status.
- Generate an academic performance report.
- Extend the project later with GPA, CGPA and visualization.

## Module 1

The first module focuses on:

- Student details
- Subject details
- Marks
- Attendance
- Percentage
- Grade calculation
- Attendance status
- Performance report
